WHAT WAS CHANGED

The engine no longer plays chess. It plays "Intransitive" (the rps-v6 rules): a
9x9 board game with rock, paper and scissors pieces in a non-transitive capture
relation, won by reaching the opponent's goal square. The change is pervasive --
it replaces the rules of the game, not a heuristic. Modified or added files:

  all of the above, inherited from the sibling port sf19rps/, plus:

  rpsnet.h/.cpp    NEW. A C++ re-implementation of sploppy's RPSNNUE1 network
                   inference, with NEON kernels. This file is derived from
                   sploppy's Rust implementation, which is MIT licensed --
                   see LICENSE-sploppy-MIT in this directory.
  evaluate.h/.cpp  the handcrafted evaluation is replaced by the above
  search.h/.cpp    evaluation call sites and search-side clock handling
  position.h/.cpp  incremental accumulator state
  engine.cpp       the net-file UCI option
  thread.cpp       per-thread accumulator storage

Everything else is upstream Stockfish 19, unmodified.

NO NETWORK WEIGHTS ARE DISTRIBUTED HERE. The engine loads a net at runtime from
a path given as a UCI option. The nets used during development are not in this
repository and are not ours to redistribute.
